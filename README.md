# Shafiq Ahamed — Portfolio

Personal portfolio website of **Shafiq Ahamed**, Aspiring DevOps Engineer & Full Stack Developer.

🔗 **Live Site:** [shafiq-ahamed.vercel.app](https://shafiq-ahamed.vercel.app)

## 🛠️ Tech Stack

- HTML5 — Semantic structure
- CSS3 — Custom properties, responsive design, animations
- Vanilla JavaScript — Typed effect, scroll animations, dark/light mode
- Vercel — Hosting with automatic HTTPS

## 🚀 Local Development

```bash
# Clone the repo
git clone https://github.com/shafiq-ahamed04/portfolio.git
cd portfolio

# Open directly in browser
open index.html

# OR serve locally
npx serve .
```

## 📦 Deployment

This site auto-deploys to Vercel on every push to `main`.

```bash
git add .
git commit -m "your message"
git push origin main
# Vercel auto-deploys in ~30 seconds
```
